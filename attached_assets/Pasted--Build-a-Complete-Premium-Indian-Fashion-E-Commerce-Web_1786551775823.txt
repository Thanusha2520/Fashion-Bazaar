# Build a Complete Premium Indian Fashion E-Commerce Website

Create a fully functional, production-quality Indian fashion e-commerce website inspired by the provided reference screenshots.

The website must reproduce the **overall visual language, spacing, layout hierarchy, interactions, navigation structure, product browsing experience, product-detail experience, cart flow, and checkout flow** shown in the screenshots, while using clean, maintainable, reusable code.

Do NOT build a static mockup.

Every important UI element must have real functionality.

---

# 1. BRAND & DESIGN DIRECTION

Brand name:

**THENMOZHI DESIGNS**

Positioning:

Premium Indian ethnic fashion / handloom / sarees / salwar suits / kurtas / blouses.

Visual personality:

* Elegant
* Minimal
* Feminine
* Traditional but modern
* Premium boutique
* Spacious editorial layout
* High-quality fashion photography
* Strong focus on product imagery

Primary visual palette:

* Deep brown / earth / cacao
* Warm cream / ivory background
* Soft muted mauve accents
* White product backgrounds
* Very subtle borders
* Dark brown typography

The visual design should closely resemble the screenshots:

* Large whitespace
* Wide content areas
* Thin borders
* Generous vertical spacing
* Large product photography
* Letter-spaced navigation
* Elegant headings
* Minimal rounded corners
* Subtle hover transitions
* Premium editorial appearance

Do not make the site look like a generic modern SaaS website.

Do not use excessive gradients, glassmorphism, neon colors, heavy shadows, oversized rounded cards, or unnecessary animations.

# 35. PAYMENT

Payment gateway architecture must be implemented cleanly.

Primary example:

**Razorpay**

Support:

* UPI
* Cards
* International cards
* Wallets

Checkout should display:

"Razorpay Secure"

Payment flow:

1. Validate cart
2. Validate customer information
3. Calculate total server-side
4. Create payment order
5. Open Razorpay checkout
6. Receive payment response
7. Verify payment server-side
8. Create order
9. Clear cart
10. Redirect to order confirmation

NEVER trust the client-side price during payment.

The final price must be calculated and verified on the backend.
